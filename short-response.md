1. If you are collaborating with a classmate, the first thing you should do is to create a branch and make them different names. It is important to do this step so the main branch doesn't get messed up and the other partner can check the other persons work after.
2. Developers use branches to split from the main branch into a different branch. They use it so they can continue working without affecting the main branch.
3. Git is a command line tool that allows you to track and manage changes to your code and is the version control at the center. On the other hand, Github is a web based platform to store repos in the cloud and collaborate with other developers. It allows developers to store, track, manage, and control changes to their code. Git and github work together because git takes a snapshot of what the code looks like at the moment and every developer also has access to all changes.
4. The command sequence is wrong because "git add ." is supposed to go first, then "git commit -m "saving work"

The correct command is:
- git add .
- git commit -m "saving work"
- git push
